# WhatsApp — Route Assignment 6

Flutter 3.50 / Dart 3.14. The existing chat layout, palette, messages, and image assets are preserved. Android, iOS, and web runners are generated by the official Flutter CLI.

## Run

```bash
flutter pub get
flutter run
```

## Included

- `lib/`: the chat screen, message bubbles, and composer.
- `assets/`: the original wallpaper, avatar, Route image, and bundled Roboto fonts with their license.
- `pubspec.yaml` and platform runners.
- `demo.mp4`: an automated Flutter UI test recording captured from the Flutter engine.
- `test/chat_screen_test.dart`: checks that the chat opens, sent text is trimmed and displayed, the composer clears, and whitespace does not add a blank bubble.

The composer appends messages to the local conversation. Messages reset when the app restarts. Calls, camera, microphone, and menu actions remain visual controls from the original UI assignment; no messaging service is connected.

## Verification

Verified with Flutter 3.50 / Dart 3.14:

- Static analysis: no issues found.
- Widget test: 1 test passed, covering chat opening, two local sends, whitespace rejection, trimmed text, and composer clearing.
- Recording: 187 Flutter-rendered frames, encoded as a 15.58-second H.264 MP4 at 12 fps (780 × 1752, including the explanatory title strip).

```bash
flutter analyze
flutter test test/chat_screen_test.dart
```

The recording shows the actual Flutter-rendered chat, text entry, two local sends, and a whitespace rejection check. It is produced by an automated widget test using `flutter_tester`; no Android or iOS emulator is used. Native device builds and device-specific behavior still require the relevant SDK or device.

To reproduce its source frames:

```bash
flutter test --dart-define=RECORD_DEMO=true test/chat_screen_test.dart
```

Frames are written to `build/demo_frames/` at 12 frames per second of test time. The included video labels the capture as an automated Flutter UI test recording. The earlier illustrative HTML preview is retained only in the separate original archive.

To encode those frames with the same visible label (requires FFmpeg and the named font):

```bash
ffmpeg -framerate 12 -i build/demo_frames/frame_%04d.png \
  -vf "pad=iw:ih+64:0:64:color=black,drawtext=fontfile=/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf:text='Automated Flutter UI test recording':fontcolor=white:fontsize=24:x=(w-tw)/2:y=20" \
  -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p \
  -movflags +faststart demo.mp4
```
